# 🌐 Personal Portfolio Website using Flask

## 📌 Project Overview

This project is a personal portfolio website developed using Python Flask, HTML and CSS.

The website presents my personal information, education, skills, certifications and projects. It also includes a contact form that demonstrates how Flask handles POST requests.

## 🎯 Objective

The main objective of this project is to create a simple and professional portfolio website using Flask and understand the basics of Flask routing, templates, Jinja2 and web forms.

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Jinja2

## ✨ Features

- 🏠 Home section
- 👩 About Me section
- 🎓 Education details
- 💻 Skills section
- 📜 Certifications section
- 🚀 Projects section
- 📩 Contact form
- 🔗 GitHub profile link
- 📱 Responsive webpage
